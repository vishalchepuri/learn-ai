# RAG Learning Lab

Interactive 7-day curriculum covering RAG, embeddings, vector databases, agents, MCP, and fine-tuning — **44 topics with 55+ working interactive examples**.

## Curriculum

| Day | Topic | # Lessons |
|---|---|---|
| **D1** | Embeddings + Vector Databases | 11 |
| **D2** | RAG Pipelines | 9 |
| **D3** | Advanced RAG + Evaluation | 6 |
| **D4** | AI Agents — Architecture | 5 |
| **D5** | MCP + A2A Protocols | 6 |
| **D6** | Fine-tuning + PEFT | 6 |
| **D7** | Week 2 Capstone Project | 1 |

## Highlights

- **Interactive examples on every topic** — click a button, see the concept play out
- **No build step** — pure HTML / CSS / vanilla JS
- **Live progress tracking** in the sidebar
- Covers: word2vec, ColBERT, HNSW, pgvector, FAISS, BM25 hybrid, RRF, HyDE, multi-query, reranking, RAGAS, ReAct, MRKL, LangGraph, CrewAI, PydanticAI, MCP (transports/OAuth/registry/security), A2A, LoRA / QLoRA, TRL/DPO, Ollama, vLLM, and more.

## Run locally

```bash
python -m http.server 8000
# open http://localhost:8000
```

Or just open `index.html` in a browser.
